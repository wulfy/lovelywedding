  • Plusieurs messages
    24/12

    Suite a des demandes répétées,
    nous avons décidé de "débloquer" le nombre de messages par personne sur le livre d'or.
    Désormais, il vous est possible de nous laisser plusieurs messages! Cependant, utilisez ce droit avec parcimonie, on compte sur vous :)
    Nous avons aussi ajouté la possibilité d'éditer un message que vous avez déjà écrit.
    Cette fonctionnalité est disponible uniquement pour les messages laissés à partir d'un PC.
    Dans les autres cas, contactez nous : contact@lovelywedding.fr
